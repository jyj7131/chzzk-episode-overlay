# chzzk-episode-overlay

치지직 같이보기에서 지금 보고 있는 화(예: `신세기 에반게리온 1화`)를 **OBS 텍스트 소스에 자동으로 띄워주는** Windows 프로그램입니다.
다음 화로 넘어가면 자동으로 바뀌고, 같이보기를 끄면 자동으로 지워집니다.

> ⚠️ 개인이 만든 **비공식** 프로그램이며, 네이버(NAVER) 및 치지직(CHZZK)과 관련이 없습니다.

## 지원 환경

- **OBS Studio 28 이상 전용**입니다. (OBS에 기본 내장된 WebSocket 서버로 텍스트를 바꿉니다)
- XSplit, Streamlabs Desktop 등 **OBS가 아닌 방송 프로그램은 지원하지 않습니다.**
- PRISM Live Studio 등 OBS 기반 프로그램은 동작 여부가 확인되지 않았습니다.
- Windows 10 / 11

## 다운로드

[Releases](../../releases/latest)에서 `chzzk-episode-overlay-*.zip`을 받아 압축을 풀고 exe를 실행하세요.
설치 과정 없이 exe 하나로 동작합니다.

- 바탕화면이나 문서 폴더처럼 **쓰기 가능한 폴더**에 두고 실행하세요. (설정을 exe 옆에 저장합니다)
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 코드 서명이 없어서 나오는 안내입니다.

## 사용 방법

1. OBS에 **텍스트(GDI+)** 소스를 추가하고 이름을 정해두기 (예: `같이보기 화수`)
2. OBS → 도구 → WebSocket 서버 설정 → **WebSocket 서버 사용** 체크
3. **[서버 정보 표시]** 버튼을 눌러 나오는 서버 IP / 포트 / 비밀번호를 프로그램의 "OBS 연결" 칸에 입력
   (원컴 환경에선 서버 IP `127.0.0.1` 그대로 사용 가능)
4. 프로그램의 "텍스트 소스 이름" 칸에 1번에서 정한 이름을 똑같이 입력
5. **[연결하기]** 버튼 클릭

이후로는 프로그램을 켜두기만 하면 됩니다. 창을 닫으면 OBS 텍스트도 함께 지워집니다.

### 표시 형식 (템플릿)

| 변수 | 의미 | 예 |
|---|---|---|
| `{title}` | 제목 전체 | 신세기 에반게리온 1화 |
| `{name}` | 작품명 | 신세기 에반게리온 |
| `{ep}` | 화수 숫자 | 1 |

예) `현재 {ep}화` → `현재 1화`

### 팁

- 같이보기는 탭 대신 **별도 창**으로 띄워서 보는 것을 권장합니다. 다른 창을 클릭하거나 최소화해도 화수는 유지됩니다.
- 같이보기 창에서 다른 탭으로 바꾸거나 같이보기 탭을 닫으면 1초 뒤 텍스트가 지워집니다.
- 글자 위치·폰트·크기·색은 OBS 텍스트 소스에서 설정하세요. 프로그램은 글자 내용만 바꿉니다.
- 텍스트(GDI+) 속성의 "파일에서 읽기"는 꺼두어야 합니다.
- 투컴에서 연결이 안 되면: 송출컴 Windows 방화벽에서 OBS 허용 / OBS가 보여주는 IP는 추정값이라 틀릴 수 있으니 송출컴에서 `ipconfig`로 IPv4 주소 확인

## 동작 방식과 개인정보

- **인터넷이나 외부 서버와 통신하는 기능이 없습니다.** 프로그램이 연결하는 곳은 사용자가 직접 입력한 OBS 주소 하나뿐입니다.
- 화수를 알아내기 위해 PC에 켜져 있는 창들의 **창 제목**만 확인하며, 그 외의 정보는 읽지 않습니다.
  이 중 `치지직 같이보기 -`로 시작하는 제목만 화수 표시에 사용하고, 그 외의 창 제목은 즉시 버립니다. 어떤 창 제목도 기록하거나 저장하지 않습니다.
- OBS로 전송하는 내용은 프로그램에서 설정한 대로 편집된 화수 텍스트뿐입니다.
- OBS 연결 설정과 템플릿은 exe와 같은 폴더의 `chzzk-episode-overlay.json`에만 저장됩니다. 비밀번호는 암호화되지 않은 상태로 저장되니 이 파일을 공유하지 마세요.
- 설치 과정이 없는 프로그램이라, 지우려면 폴더째 삭제하면 됩니다.

코드가 짧으니 직접 확인해 보셔도 됩니다.

| 파일 | 내용 |
|---|---|
| [`src/main.rs`](src/main.rs) | 창 제목 변경 감지(WinEvent 후크), 같이보기 창 추적 |
| [`src/title.rs`](src/title.rs) | 창 제목에서 화수 추출, 템플릿 적용 |
| [`src/obs.rs`](src/obs.rs) | OBS WebSocket 통신 (유일한 네트워크 코드) |
| [`src/config.rs`](src/config.rs) | 설정 파일 읽기/쓰기 |
| [`src/ui.rs`](src/ui.rs) | 설정 창 |

## 배포 파일 검증

Releases의 exe는 개발자 PC가 아니라 **GitHub Actions가 이 저장소의 소스로 직접 빌드**한 것입니다([워크플로](.github/workflows/release.yml)).
빌드 증명(attestation)이 함께 기록되므로, [GitHub CLI](https://cli.github.com/)로 받은 파일이 이 저장소에서 빌드된 것인지 확인할 수 있습니다.

```bash
gh attestation verify chzzk-episode-overlay.exe --repo jyj7131/chzzk-episode-overlay
```

## 직접 빌드

[Rust](https://rustup.rs/)와 Visual Studio C++ 빌드 도구가 필요합니다.

```bash
cargo build --release
```

`target/release/chzzk-episode-overlay.exe`가 만들어집니다.

## 책임의 한계

이 프로그램은 있는 그대로(AS-IS) 제공되며, 치지직 페이지 구조 변경 등으로 예고 없이 동작하지 않을 수 있습니다.
사용 중 발생한 방송 사고나 손해에 대해 개발자는 책임지지 않습니다.
"치지직", "CHZZK" 등의 명칭과 상표는 각 권리자에게 있습니다.
